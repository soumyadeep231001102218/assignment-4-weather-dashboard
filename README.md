# Assignment 4: Weather Dashboard

A premium Weather Dashboard built with React that fetches real-time weather data from the OpenWeatherMap API.

## Features Included
- **Real-Time Data**: Displays current Temperature, Humidity, Wind Speed, Sunrise, and Sunset times.
- **Search Functionality**: Search for the weather by any city name globally.
- **Weather Icons**: Dynamic weather icons corresponding to the current weather condition.
- **Loading State**: Displays a custom loading spinner while fetching API data.
- **Error Handling**: Graceful error UI for invalid city names or API key issues.
- **Modern Glassmorphism UI**: Beautiful, fully responsive design using CSS backdrop filters.

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/soumyadeep231001102218/assignment-4-weather-dashboard.git
   ```

2. Navigate into the project directory:
   ```bash
   cd assignment-4-weather-dashboard
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. **API Key Setup**:
   Open `src/App.jsx` and replace `API_KEY` with your own OpenWeatherMap API key if you have one. (A free test key is provided for demonstration).

5. Start the development server:
   ```bash
   npm run dev
   ```

6. Open your browser and visit the live deployment to view the site: [https://soumyadeep231001102218.github.io/assignment-4-weather-dashboard/](https://soumyadeep231001102218.github.io/assignment-4-weather-dashboard/)
